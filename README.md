# 🏢 企业智能问答助手

> 一个安装即用的企业内部问答引擎。给你的 AI 助手装上"公司大脑"——问员工、查制度、看考勤、查绩效，一句话搞定。

---

## 🎯 这是什么？

这是一个 **HR / 企业内部知识问答技能**。安装后，你可以在对话中直接 **`@qa` + 你的问题**，AI 助手会自动查公司数据库和知识库来回答。

### 能问什么？

| 类别 | 例子 |
|------|------|
| 👤 **员工信息** | `@qa 王五是谁？` → 姓名、部门、职级 |
| | `@qa 张三的上级是谁？` |
| 🏆 **绩效考核** | `@qa 王五去年绩效怎么样？` |
| 📊 **考勤数据** | `@qa 李四这个月迟到几次？` |
| 📋 **公司制度** | `@qa 年假怎么算？` |
| | `@qa 病假需要什么材料？` |
| 💰 **报销规则** | `@qa 差旅报销标准是多少？` |
| 🔗 **混合查询** | `@qa 王五符合晋升条件吗？` → 看绩效 + 看制度 |
| 📄 **会议纪要** | `@qa 上次技术同步会说了什么？` |

---

## 📖 用法

### 🗣️ 日常提问

在任何对话中，像这样提问即可：

```
你：@qa 王五的部门是什么？
AI：王五的部门是产品部。

> 来源：employees 表


你：@qa 今年年假有几天？
AI：根据《人事制度》，年假计算规则为：
- 入职满 1 年享 5 天
- 每增 1 年 +1 天
- 上限 15 天

> 来源：hr_policies.md §请假类型
```

**注意：** `@qa` 必须放在消息开头。可以连续追问，引擎会自动记住上下文。

### 🔄 重置对话

```
你：@qa 清空对话
AI：好的，已清空历史记录。
```

## 👥 终端用户指南（HR / 行政人员）

### 日常使用

在 AI 对话框中直接输入 `@qa` 后跟问题，系统会自动回答并标注数据来源：

```
@qa 王五的部门是什么？
@qa 今年年假有几天？
@qa 王五符合晋升条件吗？
```

无需学习任何操作——就像在跟一个熟悉公司所有制度的老同事聊天。

### 更新公司制度

所有政策文档以 Markdown 格式保存在 `scripts/knowledge/` 目录下，直接用文本编辑器修改即可：

| 文件 | 内容 | 谁维护 |
|------|------|--------|
| `hr_policies.md` | 考勤、请假、加班制度 | HR |
| `promotion_rules.md` | 晋升标准 | HR + 技术负责人 |
| `finance_rules.md` | 报销、财务制度 | 财务部 |
| `faq.md` | 常见问题 | 各部门 |
| `meeting_notes/` | 会议纪要 | 相关人员 |

**修改方式**：
1. 找到对应 `.md` 文件，用记事本或 VS Code 打开
2. 按 Markdown 格式编辑内容（标题用 `#`，列表用 `-`，表格用 `|`）
3. 保存文件即可，系统下次查询时自动生效

**示例**：如需修改年假规则，打开 `hr_policies.md`，找到“请假类型”章节，直接修改对应行。

### 更新员工数据

员工信息、考勤、绩效等结构化数据存储在 SQLite 数据库中。更新数据需要由 IT 或了解 SQL 的同事操作：

- **员工入职/离职/调岗** → 通知 IT 更新 `employees` 表
- **每月考勤数据** → 考勤系统导出后批量导入
- **季度绩效评分** → 绩效系统同步或手动录入

> 如需新增查询内容（如新增部门或自定义报表），请联系系统维护人员。

## 🛠️ 安装指南

### 前置条件

- **Python 3.10+**
- **安装依赖**（只需一次）：

```bash
cd skills/enterprise-qa.skill/scripts
pip install -r requirements.txt
```

### 配置文件

`scripts/config.yaml` 控制数据库和知识库路径。默认即可使用，除非你想自己改：

```yaml
database:
  path: ./enterprise.db       # SQLite 数据库文件

knowledge_base:
  root_path: ./knowledge       # 知识库目录
```

### 放对位置

把 `enterprise-qa.skill` 文件夹放入你的 OpenClaw `skills/` 目录即可自动生效。

## 📂 知识库说明

如果你有 HR 同事或管理员想自己维护知识内容：

### 数据库（结构化数据）— `enterprise.db`

SQLite 数据库，包含员工信息、考勤、绩效、项目等表。用 SQLite 工具打开编辑。

> ⚠️ **修改数据库请小心**，建议找懂 SQL 的人操作。

### 知识文档（非结构化数据）— `scripts/knowledge/`

可读的 Markdown 文件，任何人都能编辑：

```
knowledge/
├── hr_policies.md         ← 考勤、请假、加班制度
├── promotion_rules.md     ← 晋升规则
├── finance_rules.md       ← 报销、财务制度
├── faq.md                 ← 常见问题问答
├── tech_docs.md           ← 技术文档（视公司情况）
└── meeting_notes/         ← 会议纪要
    ├── 2026-03-01-allhands.md
    └── 2026-03-15-tech-sync.md
```

**如何添加新知识？**
1. 在 `knowledge/` 下新建 `.md` 文件
2. 用 Markdown 写好内容（标题、列表、表格等）
3. 刷新即可，引擎会自动索引

## 🔬 工作原理

```
你提问 @qa ...
    │
    ▼
┌─────────────────┐
│ 安全检查        │  ← 防 SQL 注入、防终端命令
└────────┬────────┘
         │
┌────────▼────────┐
│ 理解你的意图     │  ← LLM 提取要查谁、查什么
└────────┬────────┘
         │
    ┌────┴────┐
    ▼         ▼
┌──────┐ ┌───────┐
│ 数据库 │ │ 知识库 │
│ NL→SQL│ │ BM25  │
└──┬───┘ └───┬───┘
   └────┬────┘
        ▼
┌─────────────────┐
│ 合并结果 → 回答  │
└─────────────────┘
```

- **数据库查询**：自然语言 → SQL 查询员工/考勤/绩效等精确数据
- **知识库检索**：BM25 算法从制度文档里找相关段落
- **混合查询**：同时查两边，结果融合，比如"王五符合晋升条件吗"

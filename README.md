# 🏢 企业智能问答助手

> 一个安装即用的企业内部问答引擎。给你的 AI 助手装上"公司大脑"——问员工、查制度、看考勤、查绩效，一句话搞定。

---

## 🎯 这是什么？

这是一个 **HR / 企业内部知识问答技能**。安装后，你可以在对话中直接 **`@qa` + 你的问题**，AI 助手会自动查公司数据库和知识库来回答。

### 能问什么？

| 类别 | 例子 |
|------|------|
| 👤 **员工信息** | `@qa 王五是谁？` → 姓名、部门、职级 |
| | `@qa 张三的上级是谁？` |
| 🏆 **绩效考核** | `@qa 王五去年绩效怎么样？` |
| 📊 **考勤数据** | `@qa 李四这个月迟到几次？` |
| 📋 **公司制度** | `@qa 年假怎么算？` |
| | `@qa 病假需要什么材料？` |
| 💰 **报销规则** | `@qa 差旅报销标准是多少？` |
| 🔗 **混合查询** | `@qa 王五符合晋升条件吗？` → 看绩效 + 看制度 |
| 📄 **会议纪要** | `@qa 上次技术同步会说了什么？` |

## 📖 用法（人类版）

### 🗣️ 日常提问

在任何对话中，像这样提问即可：

```
你：@qa 王五的部门是什么？
AI：王五的部门是产品部。

> 来源：employees 表


你：@qa 今年年假有几天？
AI：根据《人事制度》，年假计算规则为：
- 入职满 1 年享 5 天
- 每增 1 年 +1 天
- 上限 15 天

> 来源：hr_policies.md §请假类型
```

**注意：** `@qa` 必须放在消息开头。可以连续追问，引擎会自动记住上下文。

### 🔄 重置对话

```
你：@qa 清空对话
AI：好的，已清空历史记录。
```

## 🛠️ 安装指南

### 前置条件

- **Python 3.10+**
- **安装依赖**（只需一次）：

```bash
cd skills/enterprise-qa.skill/scripts
pip install -r requirements.txt
```

### 配置文件

`scripts/config.yaml` 控制数据库和知识库路径。默认即可使用，除非你想自己改：

```yaml
database:
  path: ./enterprise.db       # SQLite 数据库文件

knowledge_base:
  root_path: ./knowledge       # 知识库目录
```

### 放对位置

把 `enterprise-qa.skill` 文件夹放入你的 OpenClaw `skills/` 目录即可自动生效。

## 📂 知识库说明

如果你有 HR 同事或管理员想自己维护知识内容：

### 数据库（结构化数据）— `enterprise.db`

SQLite 数据库，包含员工信息、考勤、绩效、项目等表。用 SQLite 工具打开编辑。

> ⚠️ **修改数据库请小心**，建议找懂 SQL 的人操作。

### 知识文档（非结构化数据）— `scripts/knowledge/`

可读的 Markdown 文件，任何人都能编辑：

```
knowledge/
├── hr_policies.md         ← 考勤、请假、加班制度
├── promotion_rules.md     ← 晋升规则
├── finance_rules.md       ← 报销、财务制度
├── faq.md                 ← 常见问题问答
├── tech_docs.md           ← 技术文档（视公司情况）
└── meeting_notes/         ← 会议纪要
    ├── 2026-03-01-allhands.md
    └── 2026-03-15-tech-sync.md
```

**如何添加新知识？**
1. 在 `knowledge/` 下新建 `.md` 文件
2. 用 Markdown 写好内容（标题、列表、表格等）
3. 刷新即可，引擎会自动索引

## 🔬 工作原理（好奇的话）

```
你提问 @qa ...
    │
    ▼
┌─────────────────┐
│ 安全检查        │  ← 防 SQL 注入、防终端命令
└────────┬────────┘
         │
┌────────▼────────┐
│ 理解你的意图     │  ← LLM 提取要查谁、查什么
└────────┬────────┘
         │
    ┌────┴────┐
    ▼         ▼
┌──────┐ ┌───────┐
│ 数据库 │ │ 知识库 │
│ NL→SQL│ │ BM25  │
└──┬───┘ └───┬───┘
   └────┬────┘
        ▼
┌─────────────────┐
│ 合并结果 → 回答  │
└─────────────────┘
```

- **数据库查询**：自然语言 → SQL 查询员工/考勤/绩效等精确数据
- **知识库检索**：BM25 算法从制度文档里找相关段落
- **混合查询**：同时查两边，结果融合，比如"王五符合晋升条件吗"
